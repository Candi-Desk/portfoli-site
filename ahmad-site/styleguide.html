Design system · v1.0

AAJ Design System

The tokens, components and rules this site is built from. Three layers: primitives, semantic tokens, components. Nothing in a component references a raw value.

Foundation

8-point spacing grid, modular 1.25 type scale

Colour

One accent, one neutral ramp, measured contrast

Standard

WCAG 2.1 AA for text and interactive targets

Lineage

Material Design states, Gestalt grouping, Nielsen heuristics

01 — Principles

Four rules the system holds to

  • Hairlines, not boxes. Structure comes from rules and whitespace. A card is reserved for the one element that genuinely sits apart, so that card still means something.
  • One accent, used only for meaning. Ink blue marks actions, links, data and active state. It is never decorative, so its presence always carries information.
  • Grouping before decoration. Proximity and similarity do the work that borders and colour would otherwise be asked to do — the Gestalt principles applied as layout, not as styling.
  • The page is complete before the first animation. Motion is layered onto a document that already reads correctly with scripts disabled.

02 — Colour

Neutrals with a blue bias, one accent

The neutral ramp carries a slight bias toward the accent hue, so the page reads as one system rather than as grey plus a colour. Contrast ratios are measured against white; the AA threshold is 4.5:1 for body text and 3:1 for large text and interface elements.

Rule: #9AA2B1 fails AA for body text at 2.9:1 and is therefore never used for text — only for muted chart fills and non-essential marks. Every text token clears 4.5:1.

03 — Type

One grotesque, one monospace, a 1.25 scale

Archivo carries both display and body, which is the Swiss convention and keeps the page coherent at every size. IBM Plex Mono is reserved for labels, data values and eyebrows — the register that signals precision. Reading measure is capped at 66 characters.

04 — Space

An 8-point grid with half steps

Ten steps, from 4px to 128px. Section rhythm, component padding and gaps all draw from the same scale, which is what makes spacing look decided rather than improvised.

05 — Iconography

One stroke weight, one grid, no colour of its own

Twenty-nine glyphs drawn on the same 24×24 grid as the type, stroke only at 1.6 with round caps and joins. Nothing is filled, so no icon can out-weigh a heading, and colour is inherited from currentColor — an icon never carries a hue the surrounding text does not.

Three sizes only: 14px inside a label or a tag, 18px as the default beside text, 26px as a standalone marker in a card or callout. Any other size would break the alignment with the type scale.

Every icon is aria-hidden, because in this system the icon never carries the meaning on its own — the label next to it does. That is a deliberate constraint: it keeps the set decorative, so a screen reader hears the same page a sighted reader sees, and it removes the temptation to let a glyph stand in for a word [WCAG 1.1.1].

The set ships as one inline <symbol> sprite per page, referenced with <use>. Inline rather than an external file so the icons survive being opened from the file system, with no request and no flash of missing glyphs. The master copy is assets/sprite.html.

06 — Components and states

Every interactive element has four states

Default, hover, focus-visible and active — the state model from Material Design, applied with one visual language. Focus is never removed, only restyled, and every target clears 44 pixels.

One rail per employed role. Horizontal because the nodes are a set within one tenure, not a ranking across roles — reading them across keeps each role’s results visually bound to that role. When the nodes overflow, and only then, script marks the region scrollable, gives it a tab stop and shows the hint: a scroll affordance that cannot scroll is a lie about the interface’s own state.

07 — Motion

Three durations, one easing curve

  • 160ms — state changes on controls: hover, focus, border.
  • 240ms — navigation reveal and small positional shifts.
  • 450ms — section entry, a 12px rise with a fade.
  • 1100ms — a rail or rule drawing across, once, as a section is entered.
  • 80ms — the stagger between siblings in a group, so a grid arrives as a sequence.
  • 800ms — chart bars growing from zero, once, when they enter view.

Easing is a single curve, cubic-bezier(.2,.7,.3,1), so everything decelerates the same way. Nothing animates twice, nothing loops, and prefers-reduced-motion disables all of it while leaving the page fully legible.

08 — Accessibility

The checks this system is held to

  • Every text colour clears 4.5:1 against its surface; large display text clears 3:1 with room to spare.
  • Form controls and buttons are at least 44px tall; every other target, down to a copy button or a “read the case” link, clears the 24px floor [WCAG 2.5.8]. Only links set inside a sentence are exempt, and they are the only ones that fall below it.
  • Focus is always visible, with a 2px accent ring and 3px offset.
  • Semantic landmarks and one h1 per page, with headings in order.
  • A skip link precedes the navigation.
  • Icons are decorative and hidden from assistive technology; the meaning is always in the adjacent label [WCAG 1.1.1].
  • Horizontally scrolling regions are focusable and labelled, so they can be reached and scrolled from the keyboard — and only when they actually scroll.
  • No page scrolls sideways at any width; a region that overflows handles it inside its own container.
  • Reduced motion is honoured as a preference, not an afterthought.
  • Content is never dependent on an animation to become visible.

09 — Why this exists

A system, not a stylesheet

A portfolio could be styled page by page. Documenting it as a system instead makes three things true: a new page can be built without inventing anything, a change to a token propagates everywhere at once, and the decisions can be reviewed by someone who did not make them.

That last point is the reason this page is public. In product work, the artefact that lets other people check your reasoning is usually worth more than the artefact that shows your taste.
