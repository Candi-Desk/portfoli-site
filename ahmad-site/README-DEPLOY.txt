Deploy to a free static host (Netlify Drop or Cloudflare Pages)
1. Optional: GA4. In assets/js/consent.js set GA_ID to your Measurement ID (G-...). Until then analytics stays off.
2. Optional: Archivo font. Save the variable WOFF2 as assets/fonts/Archivo-Variable.woff2.
3. Upload this whole folder (it includes _headers) to the host. HTTPS is automatic.
4. Site address appears in canonical/og tags, robots.txt and sitemap.xml. Replace https://ahmadaljabri.netlify.app with your real address in those files.
